# 前言

{% note success no-icon %}
本服务器是对于原版生存的很大扩展，并且进入末地也更加困难，需要去十二个不同的结构中，收集到十二种不同的末影之眼才能开启末地门。
{% endnote %}

**更多结构建筑、群系以及生物**的加入，可以让喜欢探索、旅行的玩家，享受到更加沉浸式地探索，**更多Boss及地牢**的加入让喜欢冒险、挑战的玩家，可以享受到更多惊险、刺激的挑战，**更多家具、村民，再加上农夫乐事**的加入，让喜欢休闲、养老的玩家可以有更多地乐趣。

在刚进入服务器时，玩家的初始血量被设置为<font color=red>三颗心（6点血）</font>，可以通过食用未食用过的食物来提升血量上限。服务器也拥有领地功能，玩家可以通过小地图模组进行领地声明。

<u><font color=gold>光影默认是关闭的</font></u>，虽然这个服务器对于配置的要求已经很低了，但是考虑到可能有些玩家的电脑可能比较老旧，所以默认关闭光影。对于配置足够的玩家，推荐打开游玩，享受你的旅程，欣赏MC中无与伦比的美景。

服务器没有具体要求和玩法，大家可以随意发挥自己的创意，希望大家玩的开心。
